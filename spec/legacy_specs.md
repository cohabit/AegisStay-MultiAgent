# 历史规格与记录索引

本文件将旧专题设计与当前发布要求区分开。**当前规范从 [主规格](specification.md) 进入，以 [验收标准](acceptance_criteria.md)、[实验方案](experiments.md) 和 [机器追溯映射](traceability.json) 作为实施与验证入口。**

历史专题保留当时的背景与设计意图，不自动代表已经实现、仍适用或已经完成验收。文中“真实酒店”“工业级”“零延迟”“高并发”等描述不是能力证据；数量、吞吐、时延与模型效果必须以当前代码、原始日志和清晰口径核对。旧商业会员政策仅属于 `standard` 回归数据，不能授予 `academic` 学术接待权益。
