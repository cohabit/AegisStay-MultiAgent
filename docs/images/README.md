`guest-history.jpg` 来自同日稍后的服务可靠性复核：独立 8502 端口、离线规则与合成数据，在 16 轮共 32 条消息后翻页回到首条记录。截图在恢复默认视口后直接保存，展示独立历史归档与固定输入区；第一张送物单在后续对话已取消，底部进度与所查看的旧消息属于不同时点。另保存 1280×720 和 390×844 的 DOM 位置，见 [服务可靠性验收记录](../../spec/service_reliability_verification_2026-10-25.md)。

## 2026-10-23 API 业务操作

产品截图采集于 2026-10-23，来自本版 API 工作台 `deployed_ui.py`，Streamlit 1.66.0，浏览器默认 1280 × 720 视口。使用浅色主题、学术接待配置与离线规则模式，API 开启入住凭证、岗位鉴权和独立临时 SQLite 存储，工作台只通过 HTTP 访问业务。图片直接保存浏览器截图，没有拼接或修改内容。

房间、住客称呼、库存与工单来自仓库初始数据，不含真实住客信息或密钥。页面业务日期是测试台账日期，不能作为截图采集日期，也不代表某所学校的实际运行记录。
