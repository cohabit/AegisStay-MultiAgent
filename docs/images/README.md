# 运行截图说明

产品截图采集于 2026-10-23，来自本版 API 工作台 `deployed_ui.py`，Streamlit 1.66.0，浏览器默认 1280 × 720 视口。使用浅色主题、学术接待配置与离线规则模式，API 开启入住凭证、岗位鉴权和独立临时 SQLite 存储，工作台只通过 HTTP 访问业务。图片直接保存浏览器截图，没有拼接或修改内容。

房间、住客称呼、库存与工单来自仓库初始数据，不含真实住客信息或密钥。页面业务日期是测试台账日期，不能作为截图采集日期，也不代表某所学校的实际运行记录。

| 图片 | 页面与复现过程 |
| --- | --- |
| [operations-overview.jpg](operations-overview.jpg) | 使用员工凭据进入运营工作台，查看客房、部门待办与库存 |
| [guest-cancellation.jpg](guest-cancellation.jpg) | 前台为 1128 核验签发住客凭证；住客依次申请两条毛巾、更换浴巾、会议后两点退房；页面只显示本次入住的对话与进度 |
| [delivery-change-confirmation.jpg](delivery-change-confirmation.jpg) | 员工先确认毛巾开始派送，住客申请改为浴巾；员工页展示待确认变更及学术接待延退审批 |

界面验证还包括确认撤回后新工单变为“两件浴巾”、毛巾库存恢复，以及前台批准延退后住客收到通知。已送达物品取回与途中撤回是不同分支：前者进入待检库存，后者按未交付物资恢复可用库存。

`harness-evaluation.jpg` 是 2026-10-20 原规则工作台的历史回归截图，本轮没有重新采集，不作为当前部署工作台的产品界面。规则耗时只反映相应离线测试，不能代表模型或生产端到端延迟。最新测试结果见 [版本验收记录](../../spec/release_verification_2026-10-23.md)。
