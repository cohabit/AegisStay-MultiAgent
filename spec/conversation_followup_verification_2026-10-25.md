## 可对照的行为

| 输入或操作 | 本次判定与结果 |
| --- | --- |
| `我要两瓶水，两桶泡面，一桶泡面里装水，再拿七个避孕套` | 同时指出目录未找到泡面、避孕套；整轮不建送物单、不扣水库存 |
| 去掉避孕套后重复上句 | 仍指出泡面未知，不再退化成只送水 |
| `送两条毛巾，不要一盒饼干` | 正常预留 2 条毛巾；否定项不变成未知物品或覆盖毛巾数量 |
| `送2条毛巾，早餐一份多少钱` | 答复早餐需核验，并预留 2 条毛巾；FAQ 的“一份”不覆盖送物数量 |
| 先申请水、吹风机协调、毛巾、浴巾，再说 `我都不要了` | 取消本会话 4 单，库存恢复至申请前；协调单未占用的库存不重复释放 |
| `我不是张先生，我是刘先生` 后问 `我是谁` | 使用中性称呼，说明当前绑定房间、姓名待前台核验；不把聊天自述写成入住姓名 |
| `什么级别的会员` / `我是会员吗` | academic 按接待订单说明尚未核验；不索要卡号、手机号或身份证，不自动承诺商业会员待遇 |
| 单独 `1` / `我需要帮助` / `但我又不想让你帮助` | 分别澄清数字、询问具体服务、停止继续协助；不新增服务单，不暗中取消已存在订单 |
| `我需要你之外的帮助` | 引导联系房内公示渠道或前台，明确当前聊天尚未直接接通人工 |
| `在哪可以洗脚，健身房几点关门` | 足浴与健身房分别答复；学校配置未核验，不使用 standard 夹具的楼层/开放时间 |
| `全部取消，转人工` / `查一下我是什么等级的会员，再拿一条毛巾` | 本地信息答复与取消/送物操作同时处理，不因本地答复提前结束业务 |
| `请转人工，房间插座冒烟了` / `来两瓶水，能洗脚吗` | 保留安全报修或送水操作，同时答复人工/足浴；不吞掉同轮第二个需求 |
| 加载更早、轮询新消息、回到最新 | 首次 60 条、向前每次至多 60 条；累计去重，不替换成孤立旧页；实例/会话/入住授权变更后隔离旧缓存 |

未知数量物品检测覆盖“桶、盒、袋”等量词及无空格并列项，仍属于明确语法边界内的防漏校验，不能据此声称任意自然语言都已理解。目录内 24 项库存保持原有范围，未凭聊天新增商品或设施。

## 使用与数据边界

完整归档负责查看，模型只接收近期上下文与摘要，取消/库存操作依据结构化工单与运行时校验，不能把加载旧记录称为增加模型记忆。累计显示长会话仍会增加渲染成本；需要更大规模时再引入虚拟列表，不能静默删掉旧消息。

本地默认新建实例使用 academic；已经缓存的运行时不会被强行清空或替换。Streamlit 重绘界面不保证重载已导入的业务类，PyCharm 旧进程须重新运行才使用修复后的业务逻辑。重启前先留存未持久化的旧会话；部署使用配置好的 SQLite 归档和入住授权恢复，未配置数据库的本地内存记录不能承诺跨进程保留。
